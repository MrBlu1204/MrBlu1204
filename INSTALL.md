# Install

1. Create/open the public profile repository named `MrBlu1204` under the GitHub account `MrBlu1204`.
2. Copy `README.md` and the entire `assets/` folder into that repository.
3. Commit and push.
4. GitHub will render the GIFs and local assets directly from the repository.

The README intentionally avoids runtime GitHub-stat cards so the main visual profile does not depend on a third-party Vercel endpoint.
